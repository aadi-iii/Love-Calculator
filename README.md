# ❤️ Love Calculator (Interactive V2.0)

A romantic, interactive web application inspired by classic love compatibility calculators.

Unlike simple random percentage generators, this calculator evaluates true compatibility through **3 fun interactive mini-games**. Based on user performance, focus, communication speed, and timing, it calculates a personalized love score!

---

## ✨ Key Features (V2.0 Upgrade)

- **❤️ Playful & Romantic Navbar**:
  - `❤️ Love Calculator` Brand logo (links to Home)
  - `Home` – Primary calculator entry point
  - `How It Works` – Detailed guide explaining the 3 mini-games and scoring algorithm
  - `Fun` – Romantic relationship facts, cute trivia & interactive love fact generator
  - `Contact` – Creator spotlight (`by Aadiii`) and official social links
  - `☠️ Toxic Match` – Direct link to our sister project [Toxic Match](https://aadi-iii.github.io/toxic-match/)
- **📱 Fully Responsive Design**:
  - Glassmorphic top navigation with animated hamburger menu for mobile devices
  - Auto-closing mobile menu on navigation link selection
  - Responsive layouts audited for screens from **320px** to 4K desktops
- **🎮 3 Interactive Mini-Games**:
  1. **Heart Memory Match**: Find 6 matching heart pairs under time pressure
  2. **Love Word Scramble**: Unscramble romantic words quickly
  3. **Cupid's Arrow**: Time your shot to hit the moving heart target at peak power
- **💖 Detailed Compatibility Analysis**:
  - Animated SVG score ring
  - Game score breakdown (out of 105 max points)
  - Custom compatibility tiers and romantic feedback messages

---

## 🚀 Tech Stack

- **HTML5**: Semantic markup & multi-screen single page architecture
- **CSS3**: Custom glassmorphism, flexbox, CSS grid, CSS animations & custom media queries
- **JavaScript (Vanilla)**: DOM manipulation, state management, timer loops, and game logic

---

## 📌 How to Run

1. Open `index.html` in any web browser.
2. Enter your name and your partner's name.
3. Play the 3 mini-games and discover your love percentage!
